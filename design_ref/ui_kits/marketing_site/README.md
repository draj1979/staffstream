# LawGIQ — Marketing site UI kit

A complete public marketing homepage. Editorial display type, sober palette, single ember accent.

Designed for **1440px** width; container caps at 1280px.

## Files

| File | What it is |
|---|---|
| `index.html` | The mounted page — open this in a browser. |
| `App.jsx` | Composition of all sections. |
| `Nav.jsx` | Sticky nav with backdrop blur; drops a hairline shadow when scrolled. |
| `Hero.jsx` | Editorial display headline + lede + CTAs + product preview card. |
| `TrustedBy.jsx` | Lawfirm logo row (typographic, not images). |
| `Features.jsx` | Three-card feature trio: Research, Drafting, Verification. |
| `ProductDetail.jsx` | Dark section — "Inside the workspace" — with product screenshot. |
| `Quote.jsx` | Editorial pull-quote testimonial. |
| `Pricing.jsx` | Three-tier pricing, middle tier featured (dark). |
| `CTA_Footer.jsx` | Final CTA band + five-column dark footer. |
| `Icon.jsx` | Inline SVG icon set. |
| `styles.css` | Layout + component CSS. Imports the global tokens. |

## Interactions

- **Sticky nav** drops a 1px bottom border once the page scrolls.
- Buttons, links — all visual states wired (hover, focus). No flows.

## Source of truth

No production LawGIQ marketing site was provided, so this layout is **inferred from the brief** — not lifted from real code. Section copy is original and on-brand for the voice principles in the root `README.md`.
